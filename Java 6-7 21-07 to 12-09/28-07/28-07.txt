Conditional statements:
These are used to control the flow of program by allowing it to take decisions based on specified conditions.

if statement:
It is used when a block code to be executed when specified condition is true.

syntax:
if(condition) {
     // block of code
}


if-else:
It is used to execute one block code when specified condition is true or another block of code to be executed when condition is false.

syntax:
if(condition) {
    // if block code
} else {
    // else block code
}


if-else if:
It is used to execute different blocks of code for specified multiple conditions.

syntax:
if(condition1) {
   // block 1
} else if(condition2) {
   // block 2
} else {
   // else block
}


switch case:
It is also used when multiple conditions to check same as if else if ladder.
The only difference is we can use switch case for equating conditions.

syntax:
switch(expression/statement) {
      case value1:
            block 1;
      case value2:
            block2;
      default:
             block3;
}
